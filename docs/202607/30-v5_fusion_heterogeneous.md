# v5 战役:融合层重构 + 异构基学习器

- **日期**:2026-07-30
- **起点**:v4 3-seed 平均 clean+pp,OOF 3.63802 / Private 3.60759(私榜等效 69/4111,银牌区)
- **目标**:OOF ≤3.635,Private ≤3.605(等效前 40 名);终极目标金牌线 3.60078

## Analysis

### 当前架构的两个结构性缺陷

1. **clean 模型游离于 stacking 之外**。现流程:5 个基模型 → Ridge 二层 → 得 `stack`;再与 clean 单模型按 `pred = (1-p^α)·clean + p^α·stack`(α=0.5 网格选出)手工融合。
   - clean 模型的信息只通过一个单参数公式进入,二层 Ridge 完全没见过它;
   - α 网格是在 OOF 上选的一维搜索,而最优融合本应是 `f(clf_prob, 各模型预测)` 的多元函数;
   - 证据:exp1 显示 clean+pp 相比纯 stack 拿到 -0.0016 OOF(3.63966→3.63802),说明 clean 确有独立信息,但提取方式粗糙。

2. **基学习器全为 GBDT**。lgb / xgb / cat / huber-lgb 四个回归器同族同特征,残差高度相关,融合收益已近饱和(v3→v4 调参 + 3-seed 仅换来 0.0001 级)。stacking 的理论收益来自基模型误差去相关,当前池子缺少非树模型。

### 未挖掘的信息源

- hist 表仅对 `authorized_flag==0`(被拒)子集做了独立聚合,**授权子集没有独立画像**;授权/被拒两类行为的金额、商户、时序分布差异明显,Top 方案普遍分离聚合。

### 基础设施正确性验证

含 hub 的完整复跑中,`F0 v4-stack` = **3.639652**、`α=0.5 软融合` = **3.63802**,与 v4 实际产出的 3.63966 / 3.63802 吻合到小数第 5 位 —— 说明 v5 的基模型迁移、折划分、二层评估口径全部正确,上述负面结论不是实现错误导致的。

### 四条可复用的方法论结论

1. **本赛题的 OOF 改善已不可靠转化为 Private。** v5 在 OOF 上赚 0.00285,线上只剩 0.00006,CV-LB 偏移从 0.03043 漂到 0.02721。偏移本身在变,说明 OOF 与 Private 的差距已被"OOF 专属收益"污染。今后判据应改为:**只有能同时降低 OOF 且不缩小 CV-LB 偏移的改动才值得上线**。
2. **stacking 在基模型方差差异大时有系统性偏差。** OOF 是「9 折训练、预测 1 折」的单模型输出,test 是「10 折平均」输出。折平均对高方差模型(MLP/ET)的降噪幅度远大于低方差的 GBDT,于是二层在 OOF 上学到的权重高估了异构成员在 test 上的边际价值 —— 这解释了 B 方向的全部虚假收益。
3. **特征重要性占比 ≠ 信息增量。** 149 个新特征在 gain 排序里占到 38.3%(300 维中 115 个),但单模 OOF 反而变差 0.0018;放开到全 389 维(排除"老特征被挤掉"的干扰)后更差 0.0018→0.0018。冗余特征与已有强特征相关,同样能获得高 gain。**判据只能是 OOF,不能是重要性。**
4. **解析式后处理在线性二层里可能是冗余的。** `ev = p·(-33.219) + clean − p·clean` 恰为 `[p_cal, clean, p_cal×clean]` 的线性组合,理论上不给 Ridge/Bayes 增加任何信息 —— 实验完全符合(F3 甚至略差于 F2)。想用上解析式的先验,二层必须是非线性或带约束的,而浅 LGB 二层在此规模下过拟合(F7 最差)。

### 工程债清理(本战役的确定性收益)

- 基模型产物统一为 `outputs/base/{name}.npz`(oof + test),补上了 huber-LGB 从未落盘的 test 预测、clean 模型每次重训的浪费 —— 融合实验从「每次重训 10 分钟」变成秒级代数运算;
- 定位并记录 huber-LGB 的不可复现根因(多线程 histogram 累加顺序 × 平坦验证曲线 → best_iteration 漂移),已打开 `deterministic + force_row_wise`(代价:慢 4 倍);
- 自检从"逐元素相等"改为统计一致性,避免把正常的数值抖动误判为配置错误。

### 对后续的建议(已同步到周报第 2-3 周)

停止在模型层与融合层投入 —— 本战役已证明其边际收益为零。若继续冲金(需 0.00675),只剩两条**范式级**不同的路径:
1. **严格折内 target encoding**(card 侧类别列、merchant 侧高基数列),这是唯一还没试的强特征范式;
2. **序列模型**(交易序列直接喂 RNN/Transformer,而非聚合成静态特征),`refs/ELO/DY/gen_node2vec_input.ipynb` 与 nffm baseline 提供了图/序列方向的现成入口。

但需清醒:0.00675 是 v1→v4 全部工程改进(0.0052)的 1.3 倍,而金牌方案多依赖独特数据洞察而非常规工程。更务实的路线是**承认银牌区(69/4111, top 1.7%)为最终成绩**,把剩余时间投入方法论沉淀与工程化 —— 对实习汇报而言,"用真实私榜标尺量化每一步收益、并诚实记录三个方向证伪过程"的价值高于再刷 0.001。
