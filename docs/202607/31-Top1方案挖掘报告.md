## 方案结构(全部有原文出处)

1. **核心公式**(#82036):`final = bin_predict × (-33.21928) + (1 - bin_predict) × no_outlier`
   - `bin_predict`:outlier 二分类器概率,**CV AUC 0.914**;
   - `no_outlier`:剔除 outlier 训练的回归,CV RMSE 1.545;
   - 相对同特征直接回归 local CV **-0.015**;
   - 理论:标签近似 0/1 时分类目标优于回归目标(引 Avito 冠军 xentropy 先例)。
2. **分类器最强特征 = 交易行粒度元特征**(冠军指认 Home Credit 64503#378162,并确认 KALE 解读):
   卡级 outlier 标签贴到每条交易行 → 交易原始列上行级 LGB 二分类 → 行级概率按 card 聚合(mean/max/sum/…)→ 卡级特征。
3. **senkin(7th, #82055)回归变体**:行级标签改用 loyalty target 回归,聚合 min/sum,CV/LB +0.005~0.006(附完整代码)。
4. **对照证据**(评论区):AUC 0.908 的复现者"good but not awesome";AUC 不足者公式直接翻车(3.611/3.640);16th #82166 给出防分类器误差泄露的稳健变体(按概率分位数切 predicted non-outlier)。
5. CV 纪律:"trust local cv, public rank is nothing"(public 30% 含更多 outlier,手工置 -33 者集体翻车)。
