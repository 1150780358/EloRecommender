## 第 1 周周报(07-27 ~ 08-02):赛题调研、Pipeline 搭建与首轮刷榜

**本周重点**:从零完成竞赛调研到可复现建模管线,并完成首轮线上验证与自动化实验。

**主要工作**
1. 竞赛调研:梳理 Top10 开源方案通用提分手段(outlier 三模型法、month_diff 近期性、金额脱敏还原、分层验证),输出调研总结;
2. 数据 EDA:确认 outlier 2207 个(1.09%,-33.219 哨兵值)、installments -1/999 异常与 category_3 缺失同源、2900 万行交易时间范围与缺失分布;
3. 建模管线(elo_pipeline.py):内存压缩、业务化分层清洗、双表 196 维聚合/时序/交叉特征、方差+重要性筛选、按 outlier 分层十折、LGB/XGB/CAT 三模型 + outlier 二分类、Ridge Stacking 与加权融合、产物自动落盘;
4. 打通 Kaggle 提交链路,建立提交流水档案(docs/submissions.md);
5. 搭建全自动实验战役(nohup 脱离会话):观察月特征、clean 模型+概率后处理、Optuna 复搜,自动提交并回填记录;
6. 四轮版本迭代(v1→v4):v2 观察月锚定特征、v3 Optuna 终选参数、v4 开源方案移植特征(众数聚合 / 序列 TFIDF-SVD 嵌入 / month_lag 透视与斜率 / 系统性算术交叉)+ huber 第 4 基模型 + 3-seed 平均;
7. 私榜等级核定:通过 Kaggle API 取回真实私榜 Top200 分数表(`outputs/private_lb_top200.json`),建立「Private 分数 → 等效名次」离线标尺,替代此前的粗估;
8. v5 战役(融合层重构 / 异构基学习器 / 增量特征族):三个方向系统性验证,**全部证伪**,并沉淀四条方法论结论(详见 `docs/202607/30-v5_fusion_heterogeneous.md`)。

**关键产出与指标**
- 全量端到端 25 分钟(2900 万行特征构建 3.7 分钟);
- 单模 OOF 3.6464 × 3 → v4 四模型 Stacking OOF 3.63966,clean+后处理 OOF 3.63802 → v5 最优融合 OOF **3.63455**;outlier 分类器 AUC 0.902(rank 融合 0.9048);
- 线上:首提 Private 3.61276 → **Private 3.60753**(v5 F10 融合);
- **等级:4111 队私榜等效第 69 名(top 1.7%),银牌区中上游**(金牌线 18 名 = 3.60078,尚差 0.00675);
- 工程化:基模型产物统一为 `outputs/base/*.npz`,融合实验从每次重训 10 分钟降为秒级代数运算。

**问题与解决**
- LGB/XGB 小样本 32 线程同步开销致训练慢数倍 → 固定 16 线程;DEBUG 与全量特征缓存隔离防污染;
- 早期用 Public LB 判断进展(排名 1493/4111)误导严重,私榜大洗牌 → 改为纯 OOF 择优 + 私榜标尺换算,不再看公榜;
- huber-LGB 结果无法复现 → 逐折比对定位为多线程 histogram 累加顺序 × 平坦验证曲线导致 best_iteration 漂移,打开 `deterministic` 解决(代价慢 4 倍),自检改为统计一致性;
- **v5 揭示的核心风险:OOF 改善已不可靠转化为 Private**(OOF −0.00285 → Private −0.00006,CV-LB 偏移由 0.03043 漂到 0.02721)→ 判据升级为「降 OOF 且不缩小 CV-LB 偏移」。

**下周计划**:基于 v5 证伪结论调整方向 —— 停止模型层/融合层投入,转向折内 target encoding 与序列/图模型两条范式级路径;同步启动方法论沉淀。

## 第 2 周周报(08-03 ~ 08-09):范式级特征探索与消融归因(计划稿)

**本周重点**:v5 已证明模型层与融合层的边际收益为零,本周只做「引入新信息」与「把已有结论证据化」两件事。

**计划工作**
1. **折内 target encoding**:card 侧类别列(feature_1/2/3、观察月)与 merchant 侧高基数列(merchant_id / merchant_category_id / city_id),严格在训练折内计算均值-平滑编码后映射到验证折,防泄漏;这是唯一尚未尝试的强特征范式;
2. **序列/图模型**:交易序列直接喂 GRU/Transformer(而非聚合成静态特征),或 card-merchant 二部图 node2vec 嵌入(`refs/ELO/DY/gen_node2vec_input.ipynb` 为现成入口);目标不是单模超越 GBDT,而是提供聚合统计无法表达的信息;
3. 特征组消融:对已有 9 个特征组逐项剔除量化 ΔRMSE,把"哪些特征真正有用"从推测变成证据;
4. 误差分层分析:按活跃度 / clf 概率 / 观察月分段统计残差,定位模型薄弱人群;
5. **判据纪律升级**:任何改动须同时满足 ①OOF 降低 >0.0005(超折间噪声)②CV-LB 偏移不缩小,才允许上线。

**预期产出**:target encoding 与序列模型的 OOF 对比、消融报告(ΔRMSE 表)、误差分析笔记;【目标 Private ≤3.606(等效前 60 名);若两条范式路径均无 OOF 增益则如实记录并止损】。

**风险**:0.00675 的金牌差距是 v1→v4 全部工程改进(0.0052)的 1.3 倍,且金牌方案多依赖独特数据洞察而非常规工程 → 若本周两条路径均无增益,第 3 周即转入工程化与总结,以「银牌区 + 完整可复现体系 + 证伪记录」结题。
