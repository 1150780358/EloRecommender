# v15:NN 通道扩展 × outlier 分类头 NN 化

## Analysis

**背景**:v14 后等效第 7(3.59764),距第 6(3.59707)0.00057——按 NN 族转化率(70%/104%)需融合 ΔOOF ≈ 0.0005-0.0008。

**双路设计**:
- **A 通道 10→13**(`gru_x2`,2 层 GRU × 5 seed):新增 ① 商户新鲜度序列(每月首现商户占比,探索行为衰减轨迹;new 段恒 1、首月恒 1,信息在 hist 中后期)② 单笔金额 std 序列(波动轨迹)③ 周末占比序列(习惯漂移)。
- **B outlier 分类头 NN 化**(`gru_c`,同架构 BCE,早停按 AUC × 5 seed):当前 p_cal/ev 元特征全源自 LGB clf(AUC 0.90586,冠军 0.914,还差 0.008);outlier = 评估窗零活动,即"活跃轨迹衰减到零"的序列形状,NN 主场。产出概率与 f_clf **算术平均**(标度一致,isotonic 可校准)为新 p 源 → F32/F33(p_src 升级版全池)。
- 存放纪律:回归成员进 `outputs/base_nn/`(NREG 自动吸收);**分类概率进 `outputs/base_nn_clf/`**(独立目录,防被误当回归成员)。

**判据**:max(新 F31, F33) vs F31 现值 **3.62062**,ΔOOF>0.0005 → 单候选上线;B 路若 NN AUC 明显低于 LGB 且 ens 无增益,单独记录证伪。
