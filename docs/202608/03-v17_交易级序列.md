# v17:交易级序列模型(冲第 6 重启)

## Analysis

**背景**:收官定位第 7(3.59764),第 6(3.59707)差 0.00057,需融合 ΔOOF ≥ 0.0006(按 NN 族转化率 70-104%)。月度聚合序列(v13/v14)收益已耗尽;**交易级序列**是信息保真度的下一级:月内间隔模式、品类转移轨迹、逐笔金额形状,均在月度聚合中不可见。v16 的反面印证(序列载体信息无法标量化回树)同时说明:这类信息只有序列模型能吃,与树池天然异构。

**设计**(第一版直接监督,不做预训练——若直接监督无信号,预训练难救;若有,再加码):
- **token**:每卡 hist(auth=1)+new 按时间升序取最近 **128** 笔,pad 前置。数值 7:log1p 金额、log1p 距上笔天数、month_lag/13、星期、周末、分期、is_pad;类别 2:merchant_category(factorize,emb 8)、subsector(emb 4);
- **模型**:emb 拼接 → Linear(64) → GRU(96) → concat 静态 5 列 → MLP head(与 v13 同构,静态刻意瘦);
- **训练**:MSE、AdamW 1e-3、bs 512、早停 patience 4;**5 seed 分双卡**(cuda:0×3 + cuda:1×2),777 折协议;
- **判据**:`n_gru_t` 进池(NREG 自动吸收),新 F31 vs 当前 F31 **3.62062**,ΔOOF>0.0005 → 单候选上线;不足记证伪,项目终局收官。

**成本**:数据构建 ~10 分钟(6100 万行 sort+散射);训练 128 步 ≈ 8× 月度版,单 seed 10 折 ~20 分钟,双卡总 ~1 小时。
