# v14:NN 族纵深(多 seed / 通道扩展 / Transformer)

## Analysis

**背景**:v13 GRU(单 seed,16×7 通道)融合增益 −0.00179,Private 3.59868,等效第 10 名。距第 9 名(3.59801)0.0007,按 70% 转化率需融合 ΔOOF ≈ 0.001。GRU 单折 15s(4090),NN 族试错近乎免费,是当前性价比最高的纵深方向。

**三路设计**(一轮做完,单次融合判据,不迭代调参):
- **A 多 seed 平均**:v13 折间 RMSE 3.645~3.732,初始化噪声显著;5 seed 平均是最便宜的确定性改善(降单模噪声,融合权重更稳);
- **B 通道扩展 + 2 层 GRU**:7→10 通道,新增 **被拒交易逐月笔数/占比**(hist auth=0 序列 —— 信用恶化的时间形状,树模型只有静态均值版,是"新信息+异构"双属性通道)与城市广度;
- **C Transformer encoder**(d64/4头/2层,mean-pool):NN 池内部异构,与 GRU 递归归纳偏置不同。

**工程**:中间产物(单 seed npz)存 `outputs/nn_parts/`(避免污染融合池目录);`outputs/base_nn/` 只放平均后成员:gru(A)、gru_x(B)、trf(C)。v13 单 seed 版留档 nn_parts/gru_v13_1seed.npz。v5_fusion 改为动态吸收全部 n_ 成员(F30/F31 语义升级为"全池+NN 族")。双 4090 并行(gru 族 cuda:0,trf cuda:1)。

**判据**:新 F31 OOF vs 旧 F31 **3.62162**,ΔOOF>0.0005 → 单候选上线;不足记证伪、NN 族收官。
