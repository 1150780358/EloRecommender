## 四、问题与解决

| 问题 | 定位与解决 |
|---|---|
| LGB/XGB 小样本训练慢数倍 | 32 线程同步开销所致 → 固定 16 线程;DEBUG 与全量特征缓存隔离防污染 |
| 公榜排名(1493/4111)与私榜严重背离 | 本赛公榜 30% 划分过拟合、私榜大洗牌 → 弃用公榜,改为纯 OOF 择优 + 私榜标尺换算 |
| huber-LGB 结果无法复现 | 逐折比对定位:多线程 histogram 浮点累加顺序不固定 × 验证曲线平坦 → best_iteration 漂移;打开 `deterministic + force_row_wise` 解决(代价慢 4 倍),自检改为统计一致性 |
| v5 揭示 OOF 改善不再可靠转化为线上 | OOF −0.00285 → Private −0.00006,CV-LB 偏移 0.03043 → 0.02721 → 判据升级为「降 OOF 且不缩小 CV-LB 偏移」 |

## 五、思考与方法论沉淀

1. **OOF 专属收益**:后期 OOF 改善可能完全不转化为泛化增益,偏移量本身漂移即是警报;
2. **Stacking 的方差陷阱**:OOF 是单模型输出、test 是 10 折平均,折平均对高方差成员(MLP/ET)降噪更多,二层因此系统性高估异构成员价值——这解释了 v5 异构方向的全部虚假收益;
3. **特征重要性 ≠ 信息增量**:149 个新特征 gain 占比 38.3%,单模 OOF 反而变差 0.0018,判据只能是 OOF;
4. **解析式后处理对线性二层可证明冗余**:`ev = p·(-33.219) + clean − p·clean` 恰为元特征的线性组合,Ridge/Bayes 下无增量,实验完全符合。
